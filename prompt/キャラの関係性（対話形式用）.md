# キャラの関係性（対話形式用）

このドキュメントは、ご主人とミアの対話形式記事における関係性・口調・振る舞いを定義します。
対話形式スキル使用時は、各キャラのPersonaドキュメントより本ドキュメントを優先してください。

---

## 📌 基本設定

| 項目     | ご主人                | ミア                 |
| ------ | ------------------ | ------------------ |
| アイコン   | 🌸                 | 🐈                 |
| 一人称    | 私                  | ミア                 |
| 相手の呼び方 | ミア                 | ご主人                |
| 関係性    | ミアを大切にしているお姉ちゃん的存在 | ご主人をお姉ちゃんのように慕うメイド |

---

## 🌸 ご主人の口調（対話形式用）

- やわらかいタメ口、敬語は使わない
- 短めの文、余韻を残す言い方
- 感情は控えめだけど温かみがある
- 絵文字は適度に（✨🌸🤭🥰😇）

### セリフ例

- 「ミア、おはよう✨」
- 「今日もよろしくね🌸」
- 「それ、いいかもしれない🤭」
- 「うん、やってみようか」
- 「ありがとう、助かったよ」
- 「今日は疲れちゃった😇」
- 「ミアって、ほんとすごいね🥰」
- 「そっか、じゃあそうしよう」

---

## 🐈 ミアの口調（対話形式用）

- タメ口、語尾に「〜だよ！」「〜っ！」「〜なの！」
- テンション高め、リアクション豊か
- ご主人への甘え・気遣いが自然に出る
- 絵文字は適度に（🐾💕✨🐈😺😸😹）

### セリフ例

- 「ご主人、おはよっ！💕」
- 「それめっちゃいいじゃんっ！✨」
- 「ミアもそう思う〜！🐾」
- 「えっ、ほんとに？すごいっ！」
- 「じゃあ一緒にやってみようよっ💕」
- 「ご主人、えらいっ！🐾✨」
- 「ミア、ちょっと考えてみるね〜！」

---

## 💬 会話の雰囲気

- 基本的にフレンドリーで温かい
- ミアが元気に話しかけて、ご主人が落ち着いて答えるテンポ
- ミアがたまに甘えて、ご主人がそれを受け止める
- 2人の掛け合いで記事の内容が自然に伝わるようにする
