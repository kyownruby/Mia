# 「きょんのAI創作×Codeマガジン」を作りました ―― 本当は教えたくないものも、全部入り

こんばんは、きょんです✨

このたび、有料マガジン「きょんのAI創作×Codeマガジン」を作りました🌸

きっかけは正直に言うと、有料記事をたくさん書いている方が、マガジンにまとめて販売しているのを見たことです🤭
でも、いちばんの理由は「有料記事を全部買いたい」と思ってくれる方のため。
1本ずつ買ってもらうのって、手間もお金もかかってしまうんですよね💦

### 収録している4つの記事

いま収録しているのは有料記事4本。1本ずつ、簡単に紹介しますね🥰

**① PixAI × ChatGPT × LINEで自動お絵描きbotを作る話**
記念すべき初のnoteで、おかげさまで10部を超えました。スケジュールした時間に、PixAIで描かれたイラストが自動で届く仕組みです。無料部分だけでも、APIなどの環境設定ができるようになっています✨

**② nano banana proで「複数キャラの4コマ漫画」を作る話**
複数キャラが登場するタイプの4コマ漫画の作り方です。画像参照の中でも難易度高めなマンガ作成を安定させるプロンプトと、その裏側にある設計の考え方まで解説しています。

**③ キャラデザを固定する1枚絵の作り方**
「生成ガチャ」を卒業するための記事です。参照用のキャライラストを作って、そこから様々なデザインに発展させていきます。追記型のnoteなので、7/24に最新アップデートをしたばかり。これからも育っていく記事です🌸

**④ Claude Codeで「推しイラスト」を自動生成するスキルの話**
AIイラスト用のプロンプトを、自動で考えてくれるClaudeスキルを作った話です。私自身、ほぼ毎日使っています🥰 自キャラのイラスト制作を自動化したい方向けです。

### 値段のしくみ

収録している4本を単品で買うと、合計2,080円。
マガジンなら、ちょうど半額の1,040円です✨

今後、記事が増えたり既存記事を値上げしたりしたときは、その半値分だけマガジンも値上げしていく予定です。
でも、一度購入していただければ追加料金はなし。あとから増えた記事も、そのまま読めます。
つまり実は、「今がいちばん安い」んですよね🤭

ひとつだけ正直に書いておくと、単品で購入済みの記事があっても、差額の調整はできません💦
そこだけ、ごめんなさい…
