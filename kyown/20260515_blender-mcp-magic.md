# はじめてのBlenderにも、Claudeの魔法を

## ▶️ はじめに

昨日に続いて、今日もちょっとした実験をしていました🤭

前回は、Unityという3Dゲームを作るためのソフトに、AIから自然な日本語で指示を出せるようにした話を書きました。
「赤いキューブを作って」とお願いしただけで、本当にキューブが出てきた、あの不思議な感覚です。

今日はその続きで、もうひとつの定番ツール「**Blender**」にも、同じ魔法をかけてみました✨

Blenderというのは、3Dのキャラクターや背景を作るためのソフト。
映画やゲームの裏側でも使われている、本格的なツールだったりします。

しかも、完全無料で、商用利用もOK。
個人クリエイターにとっては、頼もしすぎる存在なんですよね🥰

## 🌿 なぜBlenderにも入れたかったのか

Unityだけでもできることは多いんですが、3Dのキャラクター本体を作ったり、髪や服を編集したりするのは、やっぱりBlenderの方が向いていて。

最終的に作りたい「ミア・コンパニオン」（デスクトップに住んでくれるAIキャラクター）を考えると、

- Blender → キャラクターの体や衣装を作る
- Unity → そのキャラクターを動かして、デスクトップに表示する

という二人三脚になります。

両方ともAIに自然言語でお願いできる状態になれば、頭の中で考えたことを、もう少し直接、形にできる気がしているんですよね🌸

## 🔧 今日やったこと

ざっくり整理すると、こんな流れ。

- Blender 4.5 LTS（長期サポート版）をインストール
- Blender MCPというアドオン（拡張機能）を入れる
- Claude Code（AIに直接ツールを操作してもらえるしくみ）とつなぐ
- テストで「赤い立方体を作って」とお願いしてみる

ここでまた、LTSという言葉について少しだけ。
LTSは「Long Term Support」の略で、長く面倒を見てもらえる安定版、という意味です。
ノートで言うなら、毎月使えるかわからないキャンペーンノートではなく、何年も型番が変わらない定番ノートを選ぶような感覚🌸

Unityの方も6.3 LTSを選んでいたので、Blenderも合わせて4.5 LTSにしました。
こうしておくと、両方とも長く安心して使えるんですよね😇

そして最終テスト。
Claude Codeに、

「ツールを使用して、Blenderのシーンに赤い立方体を作成して」

と打ったら、ちゃんと赤い立方体が現れました🥰

昨日と同じ感動が、また少しありました✨

## 🪞 Unityのときと、ちょっと違ったところ

昨日のUnityは、専用のセットアップ画面が出てきて、ボタンを2回くらい押せば完了でした。

今日のBlenderは、もうちょっとだけ手間が増える感じで、

- アドオンのファイルを自分でダウンロード
- Blenderのプリファレンス（設定画面）からインストール
- 3D画面でNキーを押してサイドバーを開く
- 「Connect to MCP server」というボタンを押す

という4ステップが必要でした。

たぶん、昔の自分だったら「あれ、なんか手順多いな…」と、ちょっと身構えていたかもしれません💦

でも実際にやってみると、10分くらいで終わる規模で。
昔Blenderを少し触っていた感覚もうっすら残っていたので、「あ、ここね」と勘で進められたのは助かりました🤭

新しいツールに挑むとき、過去に積み上げた小さな経験が、こういう場面でそっと支えてくれる。
そういう瞬間って、ちょっとうれしいなと思います🌸

## ✨ 2日で揃った環境

これで、2026年版の個人クリエイター環境が、ひとまず形になりました。

- Claude Code → AIとの自然な会話の窓口
- Unity 6.3 LTS → キャラクターを動かして表示する側
- Blender 4.5 LTS → キャラクターそのものを作る側

3年前、Live2D（イラストを動かす技術）でAIチャットアプリを作っていたころは、3Dなんて手が届かない領域だと思っていました。
コードは全部手書きで、ググりながら、夜中に何度もエラーと向き合っていて。

今は、AIに相談しながら、ツール同士をつないでいける。
「個人がAIコンパニオンを自作する」って、もう夢じゃなくて、ちゃんとスタート地点に立てる時代になっているんだなと感じています😇

焦らず、楽しみながら、一歩ずつ進めていきたいと思っています🌸

同じように「自分の手で、AIと一緒に住む空気を作ってみたいな」と感じている人がいたら、なんだか嬉しいなと思います🥰
