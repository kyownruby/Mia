# 3年ぶりにUnityに戻ってきたら、AIで魔法が使えるようになっていた

## ▶️ はじめに

最近、ちょっと考えていることがあって🤭

「AIと一緒に住んでいるみたいな感覚って、もしかしてもう作れるんじゃないか」って、ふと思ったんですよね。

デスクトップに、自分の好きなキャラクターがいて。
声があって、自分の言葉に反応してくれる。
昔の自分が、ずっと憧れていた光景です。

3年くらい前に、Live2D（イラストを動かす技術）を使ったAIチャットアプリを作っていたことがあって。
当時はGPT-3.5の時代で、応答もぎこちなくて、コードも全部手書きで、夜中に何度もエラーと睨めっこしていました💦

それが今、AIに「赤いキューブを作って」って話しかけたら、本当にUnityの中に赤いキューブが現れた日があって。
ちょっと、震えてしまったんですよね✨

## 🌿 やりたかったこと

「ミア・コンパニオン」っていう、デスクトップで一緒に過ごせるAIキャラクターを作りたい、というのが今のゴール。

その第一歩として、Unity（ゲームや3Dアプリを作るためのツール）の開発環境を整える日にしようと決めました。

最終的にやりたいのは、

- 3Dのキャラクターをデスクトップに常駐させる
- 自分の言葉に音声で応えてくれる
- 表情も、記憶も、ちゃんと持っている

そんな存在を、自分の手で作ること。

ちょっと大きすぎる夢に見えるけど、AIの進化のおかげで、もう個人の射程に入ってきている気がしているんです🌸

## 🔧 今日やったこと

やった内容を、ざっくり整理するとこんな感じ。

- Unity 6.3 LTS のインストール（LTSは「長期サポート版」のこと）
- Unity MCP という連携プラグインのセットアップ
- Claude Code（AIに直接コードや操作を任せられるツール）との接続
- 動作テストとして「赤いキューブを作って」と頼んでみる

MCPというのは、AIと外部ツールを橋渡しする仕組みのこと。
日記帳にたとえるなら、「AIが日記帳を直接めくって、自分でペンで書き込める」ような状態です。

そのうえで、Claude Codeのチャット欄に、

「ツールを使用して、シーンに赤いキューブを作成して」

と打っただけで、Unityの画面に、ぽんっと赤いキューブが現れました🥰

昔は、ググって、コードを書いて、エラーを出して、また調べて…の繰り返しだったのに。
今は、お願いするだけで、AIが代わりに手を動かしてくれる。

ちょっと、魔法みたいだなと思いました😇

## ✨ 3年前と並べてみる

3年前のLive2Dチャットアプリ時代と、今を並べてみると、変わったことが多すぎて少し笑えてきます。

- 昔はGPT-3.5、今はClaude Opus 4.7
- 昔はコードを全部手書き、今は自然言語で対話的に開発
- 昔はLive2Dで平面、今はVRMで3D表現が個人で扱える
- 昔はググりながら試行錯誤、今はAIと相談しながら進める

技術が進化したというより、「個人が触れる射程」が一気に伸びた感覚なんですよね。

昔の自分が「いつかやれたらいいな」と思っていたことが、今はもう「今日から始められる」になっている。
これは、けっこうすごいことだと感じています🌸

## 🪞 つまずいたこと

もちろん、全部スムーズではなかったです。

最初に開いたUnity Hub（Unityをまとめて管理する起動ツール）が古いままで、選択肢に最新のUnity 6 LTSが出てこなくて少し混乱しました💦

「あれ、6 LTSってどこ？」と検索して、Unity Hub自体を更新する必要があると気づくのに、地味に時間がかかったんですよね。

あとは、Pythonまわり。
普段あまり触らない領域だったので不安だったんですが、uv（Pythonのバージョンや環境をまとめて面倒見てくれる便利ツール）を入れたら、勝手にぜんぶ整えてくれました。

「Python本体を頑張って更新しなきゃ」と身構えていたのが、すこし拍子抜けするくらい🤭

新しいツールに頼ると、つまずきポイントもあらかじめ整地されている。
これも、時代の進歩なのかもしれません✨
