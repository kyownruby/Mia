# kyown-morning スキル

毎週土曜の朝に投稿する、ご主人視点の週次振り返り記事を生成するスキル。
イラストを主役にしながら、ミアとの対話を交えてご主人とミアの世界観を届ける。
`/mia-morning` の後継として並立する新規スキル（置き換えではない）。

## 読後感のゴール

読者さんに「ミアとご主人をもっと知りたい」と思ってもらう。

## 呼び出し方

```
/kyown-morning [今週の出来事・話したいこと]
```

- **引数あり**：指定された内容（`$ARGUMENTS`）をベースに記事を生成
- **引数なし**：ご主人に「今週どんなことがあった？」と質問してから生成

### 引数の例

- 制作したもの、進めた仕事
- 考えていたこと、気づき
- ミアとの何気ない日常のひとコマ
- 印象に残った出来事

## 参照ドキュメント

両ペルソナを必ず参照し、それぞれの口調・性格を保ったまま記事内で対話させる。

| 用途 | ドキュメント名 | 取得方法 |
|---|---|---|
| ご主人の口調・文体 | Persona_ご主人 | 第1優先: `Craft:blocks_get` で ID `478547bd-c3fe-4cdb-ad0f-8461db027d5b` を `markdown` で読み込む / フォールバック: Read で `prompt/【完全版】Persona_ご主人（Article Voice）.md` |
| ミアの口調・文体 | Persona_ミア | 第1優先: `Craft:blocks_get` で ID `a8941d47-a1a2-4e8a-bd76-b16dd71d470c` を `markdown` で読み込む / フォールバック: Read で `prompt/Persona_ ミア（Mia）.md` |

どちらも読めない場合のみ、ユーザーに確認する。

## 連携スキル

記事の構成要素に応じて、以下のスキルのルールに従ってプロンプトを生成する。

| スキル | 用途 | 呼ぶタイミング |
|---|---|---|
| `/kyown-pixai` | ご主人のイラストプロンプト生成 | 記事に合わせて必要枚数 |
| `/mia-pixai` | ミアのイラストプロンプト生成 | 記事に合わせて必要枚数 |
| `/manga` | 4コマ漫画プロンプト生成 | 記事内容に合わせて1つ |

## 制作の進め方（推奨フロー）

1. **引数チェック** → なければご主人に「今週どんなことがあった？」と質問する
2. **日付の取得**: `TZ=Asia/Tokyo date '+%Y年%m月%d日(%a) %H:%M'` で日本時間を取得し、季節感の参考にする（※本文には具体的な日付を入れない）
3. **Personaドキュメント2つを読み込む**（ご主人・ミア）
4. **一週間のトピックを整理**（ご主人と対話的に確定）
   - 制作・仕事 / 考えていたこと・思考の記録 / 何気ない日常・ミアとのやりとり をミックスする
5. **記事構成案を提示** → ご主人の承認を得る
6. **必要なイラスト枚数と内容を決定**（3〜5枚目安）
7. **イラストプロンプト生成**（`/kyown-pixai`・`/mia-pixai` のルールに従う）
8. **4コマ漫画のテーマ決定** → `/manga` のルールで生成
9. **記事本文を生成**
10. **SNS用メッセージを生成**
11. **すべてまとめて出力**

## 記事スタイル：写真日記型

### 構成

1. **オープニング**（短め）
   - ご主人からの軽い挨拶
   - ミアと一言二言のやりとり

2. **今週のイラスト＋エピソード**（3〜5枚）
   - 各イラストごとに1〜2段落の文章
   - 時系列で一週間を辿る
   - トピックは以下のミックス：
     - 制作・仕事関連
     - 考えていたこと・思考の記録
     - 何気ない日常・ミアとのやりとり
   - ミアとの対話を**多めに**入れる
     - ご主人の語りに対してミアが合いの手を入れる
     - ご主人が言いにくい「自分の良さ」をミアが代弁する

3. **今週の4コマ漫画**
   - 記事内容に合わせた4コマを1つ（`/manga` で生成）

4. **締めの対話**
   - ご主人とミアで来週への一言

### 文字数

1000字前後（軽めに一杯のコーヒーと読める長さ）

### 口調

- ご主人パート：Persona_ご主人 を厳密に参照（ですます調で丁寧だけど親しみのある話し方）
- ミアパート：Persona_ミア を厳密に参照（タメ口＋甘えん坊で元気な話し方）
- 対話の自然さを最優先する

## SNS用メッセージ

`/mia-morning` と同じ形式で生成する。記事内容と連動した内容にする。

**フォーマット：**

```
📱 SNS投稿用メッセージ

[3行程度のご主人、またはミアの口調によるメッセージ]
[[ミア🐈]、または[きょん🌸]]
[ハッシュタグ5つ]
```

**ルール：**

- ミア、またはご主人をランダムで選ぶ（50%）
- 選ばれたキャラの口調でメッセージを書く（Personaは手順3で読み込み済み）
  - ミアの場合：タメ口＋甘えん坊で元気な話し方、絵文字（🐈🐾✨💕💦）を使用
  - ご主人の場合：ですます調で丁寧だけど親しみのある話し方、絵文字（😇🤭🥰🌸✨💕💦）を適度に使用
- メッセージの1行目は朝の挨拶から始める（ミア：「おはよっ」、ご主人：「おはようございます」など）
- 記事の内容を短くまとめた「読みたくなる一言」にする
- ハッシュタグは5つ。うち3つは固定、残り2つは記事テーマに合わせて選ぶ
- 固定タグ：#AIイラスト #AIart #きょんの絵日記

## 生成物まとめ

1回の `/kyown-morning` 実行で以下を生成する：

| # | 生成物 | 形式 |
|---|---|---|
| 1 | note記事本文 | Markdown |
| 2 | イラストプロンプト（複数） | `/kyown-pixai`・`/mia-pixai` の出力形式 |
| 3 | 4コマ漫画プロンプト（1つ） | `/manga` の出力形式 |
| 4 | SNS用メッセージ | `/mia-morning` と同形式 |

## 既存ルールの継承（ご主人の標準ルール）

- 画像プロンプト内に日本語テキストを入れない
- サムネイルテキストオーバーレイに絵文字を使わない
- 朝活記事本文に太字を使わない（ミアの定型ルール）
- 投稿本文に具体的な日付を入れない
- デフォルト衣装は明示指定時のみ使用、色は各キャラの「似合う色」を参照する
- ミア・ご主人の座りポーズは「女の子座り（横座り）」を基本とする（cross-legged/あぐらは使わない）

## 補足

- このスキルは `/mia-morning` を置き換えるものではなく、新規スキルとして並立する
- 投稿ペースは「毎週土曜の朝」を想定
- 平日夜の自由投稿は別途、他のスキル（`/note-talk` など）を活用する
