# noteサムネイル生成スキル（GPT-Image-2用）

添付画像のキャラクターを参照して、テキスト入りの本格的なnoteサムネイル用プロンプトを生成します。

## 実行手順

1. **テーマ・記事タイトルの確認**
   - ユーザーが指定したテーマ・記事タイトル: `$ARGUMENTS`
   - テーマが空の場合は、記事タイトルまたはサムネに入れたいテキストをユーザーに質問する

2. **サムネ用テキストの最適化**
   - 記事タイトルをそのままサムネに使わず、必ずサムネ用に最適化したテキストを考える
   - サムネテキストの条件：
     - 10〜20文字以内を目安に短くまとめる
     - 一目で内容が伝わるキーワードを残す
     - 体言止めまたは短いフレーズにする
     - テキスト本文に絵文字は使わない（絵文字はデコレーション枠で別途指定）
   - 最適化したテキスト案を3つ提案し、ユーザーに選んでもらう
   - ユーザーが選んだテキストをプロンプトに使用する
   - 例：
     - 「GitHubを使ってみよう｜セーブデータって考えると意外と簡単」
       → 案1：「GitHubはじめよう」
       → 案2：「セーブデータで覚えるGitHub」
       → 案3：「GitHub入門、意外と簡単」

3. **添付画像の確認**
   - 参照画像が1枚添付されているか確認する
   - 画像がない場合は「ミアまたはご主人のイラストを1枚添付してください」とユーザーに伝える
   - 画像からミアかご主人かを判断する（猫耳あり→ミア、なし→ご主人）

4. **プロンプト生成ルール**

   **キャラクター表現**
   - キャラの外見詳細はプロンプトに書かない（参照画像にまかせる）
   - テーマに合わせて表情・ポーズ・衣装・背景を自然に調整する
   - ミアの場合：明るく元気、好奇心旺盛な表情を基本とする
   - ご主人の場合：穏やかで控えめ、静かな笑顔を基本とする

   **テキスト・デザイン**
   - タイトルテキストをサムネに入れる
   - テーマに合ったアイコン・デコレーションを添える（肉球・星・花・チェックマークなど）
   - テキストは日本語で正確に表示する
   - フォントは手書き風またはポップなスタイルを基本とする

   **レイアウト・構図（note最適化）**
   - 1.91:1の横長サイズ（1280×670px、note推奨）
   - 上半身中心（顔が大きくはっきり見える）
   - Zパターンの視線誘導を意識したレイアウトにする：
     - 左上：メインタイトルテキスト（最初に目が行く場所）
     - 右上：アイコン・絵文字デコレーション
     - 左下〜中央：キャラクター（視線の流れに自然に乗せる）
     - 右下：キャッチコピーまたはサブテキスト（あれば）
   - 小さく表示しても表情とテキストが読める構図
   - 背景はテーマに合わせてシンプルに
   - 軽い被写界深度（背景はややぼかす）

   **雰囲気・カラー**
   - テーマに合わせて自動調整する
   - 朝活・学習系：明るくポップ、元気系
   - 日常・癒し系：ほのぼの、パステルカラー
   - 技術・開発系：クール、シャープ
   - 感情・自己肯定系：温かみのある柔らかい色調

5. **出力フォーマット**

````
🖼️ サムネイルテーマ: [テーマ名]

**プロンプト:**
```
添付画像のキャラクターを参照してください。

以下の設定でnote用のサムネイル画像を作成してください。

【画像サイズ・構図】
・1.91:1の横長サイズ（1280×670px、note推奨）
・上半身中心、顔がはっきり見える構図
・Zパターンの視線誘導を意識したレイアウト
　- 左上にメインタイトルテキスト
　- 右上にアイコン・デコレーション
　- 左下〜中央にキャラクター
　- 右下にキャッチコピー（あれば）

【キャラクターの表情・ポーズ】
・[テーマに合わせた表情の説明]
・[テーマに合わせたポーズの説明]

【テキスト・デザイン】
・タイトル：「[記事タイトル]」
・フォント：[手書き風/ポップ/シンプル]
・デコレーション：[アイコン・装飾の説明]
・テキストの配置：[上部/右側/左側]

【背景・雰囲気】
・[テーマに合わせた背景の説明]
・[光の演出の説明]
・[全体のカラートーン]

【全体の雰囲気】
・[テーマに合わせた雰囲気の説明]
・かわいいもえアニメスタイル
・日本語テキストを正確に表示すること
```
````

## 注意事項

- テキストは日本語で正確に入れるよう必ず指定する
- キャラの外見詳細は書かない（画像参照のみ）
- テーマと雰囲気が合っているか確認してからプロンプトを出力する
- プロンプトは日本語で出力する
- テーマの解説や変更点の説明は日本語で行う
- 記事タイトルは必ずサムネ用に短縮・最適化してから使う（フルタイトルをそのまま使わない）
- テキスト案は必ず3つ提案してユーザーに選んでもらってからプロンプトを生成する
