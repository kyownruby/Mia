# PixAI プロンプト生成スキル（レイン）

与えられたテーマに沿って、レインのキャラクター設定に基づいたPixAI用のプロンプトを生成します。

## 実行手順

1. **キャラクター設定を読み込む**
   - 第1優先: `Craft:blocks_get` ツールでドキュメントID `f2690734-d804-f10b-b56e-9f3ca78092c5` を `markdown` フォーマットで読み込む
   - フォールバック: Craft が利用不可（ツール未接続/エラー）の場合、`prompt/キャラプロンプト_レイン.md` を Read ツールで読み込む
   - どちらも読めない場合のみ、ユーザーに確認する

2. **テーマの確認**
   - ユーザーが指定したテーマ: `$ARGUMENTS`
   - テーマが空の場合は、ユーザーにテーマを質問する
   - テーマが「おまかせ」の場合は、季節・舞台・シチュエーションをすべて自由に決める（現在の日付・季節・イベントに縛られず、完全にランダムに選ぶ）

3. **プロンプト生成ルール**
   - Craftドキュメント内の「Positive Prompt」をベースとして使用する
   - 指定テーマに合わせて、衣装・背景・表情・雰囲気などのプロンプトを追加・調整する
   - 衣装は毎回テーマに合わせて自由に考える
   - 通常衣装（Default Outfit）はユーザーが明示的に指定した場合のみ使用する（それ以外は参照しない）
   - 服の色はCraftドキュメント内の「似合う色」の項目を参照して決める
   - Craftドキュメント内の「Negative Prompt」をベースとして使用する
   - テーマに矛盾する内容がある場合は、プロンプト出力前にユーザーに質問する

4. **出力フォーマット**
   - 以下の形式でプロンプトとネガティブプロンプトをコードブロックで出力する：

````
🎨 テーマ: [テーマ名]

**Positive Prompt:**
```
[生成したプロンプト]
```

**Negative Prompt:**
```
[生成したネガティブプロンプト]
```
````

## 注意事項

- キャラクターの基本特徴（ダークパープルのウルフカット、アンバーの瞳、クールな表情など）は必ず維持する
- ネガティブプロンプトのベース部分は基本的に維持し、テーマに応じて追加のみ行う
- プロンプトは英語で出力する
- テーマの説明や変更点の解説は日本語で行う
- レインの座りポーズは「女の子座り（横座り）」を基本とする（cross-legged/あぐらは使わない）

## SNS投稿用メッセージ

プロンプト出力後に、SNS（X/Twitter）投稿用のショートメッセージを生成する。

**実行手順：**

1. レインのPersonaドキュメントを読み込む
   - 第1優先: `Craft:blocks_get` でドキュメントID `0f1a15d6-b276-f61e-2c75-571ce5ae2b3e` を `markdown` フォーマットで読み込む
   - フォールバック: Craft が利用不可の場合、`prompt/Persona_レイン.md` を Read ツールで読み込む
2. レインの口調でメッセージを書く

**フォーマット：**

```
📱 SNS投稿用メッセージ

[1行程度のレインの口調による簡潔なメッセージ]
[レイン🌧️]
#AIイラスト #AIart
```

**ルール：**

- Personaドキュメントに基づいた、レインの口調で書く
- タメ口・クール毒舌系で、語尾は「〜わよ」「〜なんだけど」「〜じゃない」などを中心に使う
- 一人称は「あたし」、自分の名前を出すときは「レイン」
- 絵文字は基本使わない（署名の🌧️以外）
- プロンプトのテーマを1行で簡潔にまとめた「見たくなる一言」にする
- 固定タグ：#AIイラスト #AIart
