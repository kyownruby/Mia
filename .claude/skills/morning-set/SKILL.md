# 朝活フルセット生成スキル（morning-set）

noteの朝活記事を起点に、記事本文・キャラ立ちイラストプロンプト・サムネプロンプトまでを一連の流れで生成するスキル。
ご主人を主役に、ミア・レイン・しおりのいずれかが合いの手を入れる対話形式の記事を作る。

各キャラのCraftドキュメントIDは以下の通り。`Craft:blocks_get` で `markdown` フォーマットで読み込む。

|---|---|---|

## 実行手順

### STEP 0: ヒアリング（必須）

スキル起動時に、以下を必ずユーザーに確認する。`$ARGUMENTS` でテーマが渡されていても、登場キャラは必ず聞く。

1. **テーマの方向性** — `$ARGUMENTS` が空の場合のみ確認する。
   - 候補：前向き・励まし系／AI・ツール系の学び／日常・ゆるい雑談／おまかせ
   - 方向性が決まったらテーマ候補を複数提案し、確定させる。

2. **登場する合いの手キャラ（必須ヒアリング）** — 毎回必ず確認する。
   - 選択肢：ミア／レイン／しおり
   - 複数人の同時登場も可。誰が登場するかで読み込むドキュメントを決める。

3. **文字数** — 指定があればそれに従う。なければデフォルト500字程度。

---

### STEP 1: 記事執筆（ご主人主体＋合いの手の対話形式）

1. **ご主人のPersonaを全文読み込む**（ID: `478547bd-c3fe-4cdb-ad0f-8461db027d5b`）
   - **重要**：このドキュメントは長く、ページ送り（cursor）で複数回に分かれている。**必ず最後まで読む**こと。
   - 特に末尾付近の「**💬 ご主人の記事における口調ルール → ① 基本文体**」を読み逃さない。
     - **です／ます調ベース**、少しカジュアル寄り
     - **文末は絵文字でやわらかく締める**（1文1個まで／意味を持たせて使う）
     - 「。」で終わる文は控えめ、冷たさを避け安心感を優先
   - 絵文字の役割：😇やわらかい理想／🤭迷い・照れ／🥰あたたかさ／🌸やさしい締め／✨前向きな気づき／💕共感／💦疲れ・戸惑い
   - 禁止事項：強すぎる断定、煽り・不安商法、マウント、感情の切り捨て、共感の押しつけ、過度な自己否定、情報の詰め込みすぎ。

2. **登場する合いの手キャラのPersonaを読み込む**（STEP 0 で選ばれたキャラのみ）
   - ミア：`a8941d47-a1a2-4e8a-bd76-b16dd71d470c`
   - レイン：`0f1a15d6-b276-f61e-2c75-571ce5ae2b3e`
   - しおり：`ce7ef64f-1ca1-d70b-3c67-f9a6ee80d173`
   - 各キャラの一人称・口調・ご主人や他キャラの呼び方を正確に反映する。

3. **「キャラの関係性（対話形式用）」を読み込む**（ID: `bcdf3e5a-f52d-e603-607a-01f59bfec96e`）
   - 複数キャラが登場する記事では、各キャラのPersonaよりこのドキュメントを優先する。
   - 特に**キャラ同士の呼び方**を正確に反映する：
     - ご主人→各キャラを名前で／ミアはレインを「レインちゃん」・しおりを「しおりちゃん」
     - レインはご主人を「きょん」・ミアを「ミア」・しおりを「しおり」
     - しおりはご主人を「きょんちゃん」・ミアを「ミアちゃん」・レインを「レインちゃん」
   - キャラ同士の自然な絡み（ミア↔レイン等）や、各キャラのポジション（ミア=ムードメーカー／レイン=クールなツッコミ＆お姉ちゃん的／しおり=そっと寄り添う）も踏まえる。

4. **記事を構成する**
   - **冒頭の登場キャラ凡例は入れない**（セリフが「絵文字＋キャラ名」形式なので凡例なしで誰の発言かわかるため）。
   - **合いの手・セリフのアイコン絵文字は固定**：ご主人 → 🌸　／　ミア → 🐈　／　レイン → 🌧️　／　しおり → 📖
   - ご主人の地の文（です・ます調＋文末絵文字）をベースに進める。
   - 合いの手は引用ブロック（`>`）で挿入し、**「絵文字＋キャラ名：「セリフ」」の形式**にする。
     - 例（ミア）：`> 🐈ミア：「〜」`
     - 例（レイン）：`> 🌧️レイン：「〜」`
     - 例（しおり）：`> 📖しおり：「〜」`
   - 合いの手は「会話の流れに自然に入る」程度。入れすぎず、ご主人の語りが主役。
   - 記事のトーンはテーマに合わせる（疲れ・回復系なら物語寄り＝感情7:構造3 など、ご主人Personaの温度レイヤー／テンプレを参照）。
   - 指定文字数に合わせる。

5. **記事末尾にハッシュタグを自動付与する**
   - 記事本文のいちばん最後に、登場キャラのハッシュタグを**半角スペース区切り**で記載する（noteが自動でハッシュタグとして認識するため）。
   - ご主人は必ず含める。順番は「ご主人 → 登場した合いの手キャラ」。
   - キャラとハッシュタグの対応：
     - ご主人 → `#きょん`
     - ミア → `#ミア`
     - レイン → `#レイン`
     - しおり → `#しおり`
   - 例（ご主人＋ミア登場時）：`#きょん #ミア`
   - 例（ご主人＋レイン＋しおり登場時）：`#きょん #レイン #しおり`
   - STEP 0 で選ばれた登場キャラだけを載せる（登場していないキャラのタグは付けない）。

### STEP 2: キャラ立ちイラストのプロンプト生成（PixAI）

登場した各キャラぶん、PixAI用のプロンプトを生成する。

1. **各キャラのキャラプロンプトを読み込む**
   - ご主人：`2cc222fd-2853-4f02-8fd9-9c17bfd67520`
   - ミア：`fdd82e0f-eb09-0ee9-dd49-cbfa60d1a42f`
   - レイン：`f2690734-d804-f10b-b56e-9f3ca78092c5`
   - しおり：`f39902ea-2041-76b7-d57d-d4a6a1227f8c`

2. **プロンプト生成ルール**
   - ドキュメント内の「Positive Prompt」「Negative Prompt」をベースに使う。
   - 記事内容に合わせて、表情・ポーズ・衣装・背景・雰囲気を追加・調整する。
   - **衣装は毎回テーマに合わせてランダムで新しく考える**。各ドキュメントの「通常衣装（Default Outfit）」は使わない。色は各ドキュメントの「似合う色（Color Palette）」を参照し、テーマに合った衣装を毎回オリジナルで設計する。
   - キャラの基本特徴（髪色・瞳・猫耳など）は必ず維持する。
   - **プロンプトは英語で出力**。変更点の説明は日本語で行う。

3. **出力フォーマット**（キャラごと）
   - **重要**：見出し（`🎨 テーマ:〜`）や `**Positive Prompt:**` などのラベルは**コードブロックの外**に書く。
   - コードブロックの中には**プロンプト本体だけ**を入れる（ユーザーがコードブロックをコピーしたとき、見出しやラベルが混ざらないようにするため）。
   - Positive と Negative はそれぞれ別のコードブロックに分ける。

🎨 テーマ: [テーマ名]（[キャラ名]）

**Positive Prompt:**

```
[生成したプロンプト本体のみ]
```

**Negative Prompt:**

```
[生成したネガティブプロンプト本体のみ]
```

---

### STEP 3: サムネ用イラストのプロンプト生成（GPT-Image-2）

記事に合った、登場キャラが登場するサムネプロンプトを生成する。

1. **基本仕様**
   - **note推奨のアスペクト比 1.91:1（1280×670px）**。noteの見出し画像はこの比率が公式推奨。16:9（1.78:1）で作るとnote表示時に上下が少し切れるので注意。
   - **重要な要素（キャラの顔など）は画像の中央寄りに配置する**。記事一覧・プロフィール横では中央が正方形に切り抜かれて表示されるため。
   - **文字・文章・単語・ロゴは一切入れない**（GPT-Image-2は文字を入れたがるので、末尾で強めに念押しする）

2. **参照画像を使う前提のプロンプト設計**
   - ユーザーが各キャラの参照画像を用意する前提。**見た目（髪色・瞳・服など）の描写は省く**。
   - プロンプトに書くのは「参照画像ではわからない部分」だけ：**表情・ポーズ・動き・視線・構図・全体の雰囲気**。
   - **どの参照画像がどのキャラか明示する**（例：「1枚目の参照画像のキャラクター（ご主人）」「2枚目の参照画像のキャラクター（ミア）」）。配置（左右）も指定する。

3. **構図のコツ**
   - **カメラ目線になりすぎないようにする**。複数キャラなら「お互いを見て向かい合う」自然な構図を指定すると良い。
   - 各キャラに視線の向き（誰を見ているか）を書く。
   - 記事のムードを反映した雰囲気描写を加える。

4. **言語**
   - デフォルトは日本語プロンプト（ユーザー希望に応じて英語も可）。GPT-Image-2は日本語プロンプトも読める。

5. **出力フォーマット**
   - **重要**：見出し（`🎨 サムネ用イラスト〜`）は**コードブロックの外**に書く。
   - コードブロックの中には**プロンプト本体だけ**を入れる（ユーザーがコードブロックをコピーしたとき、見出しが混ざらないようにするため）。

🎨 サムネ用イラスト（GPT-Image-2 / 1.91:1 (1280×670px) / 文字なし / [登場キャラ]）

```
[1.91:1・横長・雰囲気の導入文]

[シーン・場所の説明]

[N枚目の参照画像のキャラクター（キャラ名）：表情・ポーズ・視線・配置（中央寄り）]
（登場キャラぶん繰り返す）

【構図】：[向かい合わせ・カメラ目線回避・重要要素は中央寄り・全体ムード]

画像内には文字・文章・単語・ロゴを一切入れないこと。
```

---

## 注意事項

- STEP 0 のヒアリング（テーマ確認・登場キャラ確認）は毎回必ず行う。特に**登場キャラはテーマ指定があっても必ず聞く**。
- ご主人Personaは分量が多いので、**ページ送りで最後まで読み切る**ことを徹底する（口調ルールの読み逃し防止）。
- PixAIプロンプトは英語、記事・サムネ・各種説明は日本語。
- PixAIプロンプトの衣装は毎回テーマに合わせてランダムで考える（通常衣装は使わない）。
- 各STEPの完了後にユーザーへ確認し、修正要望があれば対応してから次へ進んでもよい（対話的に進める）。
