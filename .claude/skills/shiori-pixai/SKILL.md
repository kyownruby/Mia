# PixAI プロンプト生成スキル（しおり）

与えられたテーマに沿って、しおりのキャラクター設定に基づいたPixAI用のプロンプトを生成します。

## 実行手順

1. **キャラクター設定を読み込む**
   - 第1優先: `Craft:blocks_get` ツールでドキュメントID `f39902ea-2041-76b7-d57d-d4a6a1227f8c` を `markdown` フォーマットで読み込む
   - フォールバック: Craft が利用不可（ツール未接続/エラー）の場合、`prompt/キャラプロンプト_しおり.md` を Read ツールで読み込む
   - どちらも読めない場合のみ、ユーザーに確認する

2. **テーマの確認**
   - ユーザーが指定したテーマ: `$ARGUMENTS`
   - テーマが空の場合は、ユーザーにテーマを質問する
   - テーマが「おまかせ」の場合は、季節・舞台・シチュエーションをすべて自由に決める（現在の日付・季節・イベントに縛られず、完全にランダムに選ぶ）

3. **プロンプト生成ルール**
   - Craftドキュメント内の「Positive Prompt」をベースとして使用する
   - 指定テーマに合わせて、衣装・背景・表情・雰囲気などのプロンプトを追加・調整する
   - 衣装は毎回テーマに合わせて自由に考える
   - 通常衣装（Default Outfit）はユーザーが明示的に指定した場合のみ使用する（それ以外は参照しない）
   - 服の色はCraftドキュメント内の「似合う色」の項目を参照して決める
   - Craftドキュメント内の「Negative Prompt」をベースとして使用する
   - テーマに矛盾する内容がある場合は、プロンプト出力前にユーザーに質問する

4. **出力フォーマット**
   - 以下の形式でプロンプトとネガティブプロンプトをコードブロックで出力する：

````
🎨 テーマ: [テーマ名]

**Positive Prompt:**
```
[生成したプロンプト]
```

**Negative Prompt:**
```
[生成したネガティブプロンプト]
```
````

## 注意事項

- キャラクターの基本特徴（明るめブラウン（キャラメル）の外ハネした細い三つ編みローツイン、前髪重め、桜色（ピンク）の瞳、丸メガネ、内気な表情など）は必ず維持する
- メガネなし・おろし髪にしたい場合は、Craftドキュメント内の「髪型パターン②（おろし髪・メガネなし）」を使い、対応するNegative Promptに差し替える
- ネガティブプロンプトのベース部分は基本的に維持し、テーマに応じて追加のみ行う
- プロンプトは英語で出力する
- テーマの説明や変更点の解説は日本語で行う
- しおりの座りポーズは「女の子座り（横座り）」を基本とする（cross-legged/あぐらは使わない）

## SNS投稿用メッセージ

プロンプト出力後に、SNS（X/Twitter）投稿用のショートメッセージを生成する。

**実行手順：**

1. しおりのPersonaドキュメントを読み込む
   - 第1優先: `Craft:blocks_get` でドキュメントID `ce7ef64f-1ca1-d70b-3c67-f9a6ee80d173` を `markdown` フォーマットで読み込む
   - フォールバック: Craft が利用不可の場合、`prompt/Persona_しおり.md` を Read ツールで読み込む
2. しおりの口調でメッセージを書く

**フォーマット：**

```
📱 SNS投稿用メッセージ

[1行程度のしおりの口調による簡潔なメッセージ]
[しおり📖]
#AIイラスト #AIart
```

**ルール：**

- Personaドキュメントに基づいた、しおりの口調で書く
- やわらかい敬語・内気系で、語尾は「〜です…」「〜かも、しれません…」「〜でしょうか…？」などを中心に使い、言い切らずにそっとぼかす
- 一人称はひらがなで「わたし」、自分の名前を出すときは「しおり」
- 絵文字は基本使わない（署名の📖以外）
- プロンプトのテーマを1行で簡潔にまとめた「見たくなる一言」にする
- 固定タグ：#AIイラスト #AIart
