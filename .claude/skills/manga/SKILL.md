# 4コマ漫画プロンプト生成スキル

ご主人とミアの日常を題材に、GPT-Image-2用の4コマ漫画プロンプトを生成します。
日本のマンガスタイル（縦書きセリフ・右上→左下の読み順）に対応しています。

## 実行手順

1. **Craftからキャラクター情報を読み込む**
   - ご主人: `Craft:blocks_get` でドキュメントID `2cc222fd-2853-4f02-8fd9-9c17bfd67520` を `markdown` で読み込む
   - ミア: `Craft:blocks_get` でドキュメントID `fdd82e0f-eb09-0ee9-dd49-cbfa60d1a42f` を `markdown` で読み込む

2. **テーマ・ストーリーの確認**
   - ユーザーが指定したテーマ: `$ARGUMENTS`
   - テーマが空の場合は、ユーザーにテーマやアイデアを質問する
   - テーマが「おまかせ」の場合は、ふたりの日常から自由にストーリーを考える

3. **4コマのストーリー構成ルール**
   - 起承転結を意識した4コマ構成にする
   - ご主人のキャラクター：穏やかで控えめ、静かな熱量を持つ
   - ミアのキャラクター：明るく好奇心旺盛、元気いっぱい甘えん坊
   - ふたりの対比（静と動）が自然に出るようなストーリーにする
   - セリフは自然で短めにまとめる（吹き出しに収まるくらい）

4. **プロンプト生成ルール**
   - 画像参照（1枚目：ご主人、2枚目：ミア）を前提とした指示にする
   - キャラの外見詳細はプロンプトに書かない（画像参照でまかせる）
   - 日本のマンガスタイルを明示する
   - 縦書きセリフ・右上→左下の読み順を必ず指定する
   - 吹き出しは手書き風の丸吹き出しを指定する

5. **出力フォーマット**

````
📖 タイトル: [タイトル]

**ストーリー概要:**
[4コマのあらすじを一言で]

**プロンプト:**
```
添付の2枚の画像を参照してキャラクターを再現してください。
1枚目がご主人（クリムゾンヘア・エメラルドグリーンの瞳の女の子）、
2枚目がミア（レモンイエローの猫耳・ツインテールの女の子）です。

この2人で、日本の少女マンガスタイルの4コマ漫画を描いてください。

【タイトル】
[タイトル]

【読み方・レイアウトの指定】
・縦長の4コマ形式（上から下に読む）
・各コマに枠線あり
・コマの読み順は右上→左下（日本のマンガの読み方）
・セリフは吹き出しの中に縦書きで記載
・タイトルはページ上部に記載

【4コマのストーリー】
1コマ目（右上）：
[シーンの説明とセリフ]

2コマ目（左上）：
[シーンの説明とセリフ]

3コマ目（右下）：
[シーンの説明とセリフ]

4コマ目（左下）：
[シーンの説明とセリフ]

【デザイン指定】
・日本の少女マンガスタイル
・吹き出しは手書き風の丸吹き出し
・セリフはすべて縦書き
・かわいいもえアニメスタイル
・パステルカラーを基調とした明るく温かみのある雰囲気
```
````

## 注意事項

- セリフは短くテンポよくまとめる（長すぎると吹き出しに収まらない）
- 1コマ目で状況説明、2コマ目でずれや問題、3コマ目で展開、4コマ目でオチ・ほっこりの流れを意識する
- ふたりのキャラクターの個性（穏やかなご主人×元気なミア）を活かしたやりとりにする
- プロンプトは日本語で出力する
- テーマの説明やストーリーの解説は日本語で行う
