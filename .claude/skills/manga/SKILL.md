# 4コマ漫画プロンプト生成スキル

ご主人とミアの日常を題材に、GPT-Image-2用の4コマ漫画プロンプトを生成します。
日本のマンガスタイル（縦書きセリフ・右上→左下の読み順）に対応しています。

## 2つの入力モード

- **テーマモード**: テーマやアイデアを渡すと、ストーリーから4コマを自由に組み立てる
  - 例: `/manga 朝のお散歩`
- **対話モード**: `/note-talk` の出力（🌸／🐈の対話）を渡すと、対話のセリフを活かして4コマに圧縮する
  - 例: `/manga 🌸：「おはよ」🐈：「おはようっ💕」...`

## 実行手順

### Step 1: 入力モードを判定する

- 引数 `$ARGUMENTS` に `🌸：` または `🐈：`（半角コロン `:` 含む）が含まれている場合は **対話モード**
- それ以外は **テーマモード**（従来の動作）

### Step 2-A: 【テーマモード】キャラクター情報を読み込む

各キャラのキャラプロンプトを以下の優先順位で取得する：

- ご主人
  - 第1優先: `Craft:blocks_get` でドキュメントID `2cc222fd-2853-4f02-8fd9-9c17bfd67520` を `markdown` で読み込む
  - フォールバック: Craft が利用不可（ツール未接続/エラー）の場合、Read ツールで `prompt/キャラプロンプト_ご主人.md` を読み込む
- ミア
  - 第1優先: `Craft:blocks_get` でドキュメントID `fdd82e0f-eb09-0ee9-dd49-cbfa60d1a42f` を `markdown` で読み込む
  - フォールバック: Read ツールで `prompt/キャラプロンプト_ミア.md` を読み込む

どちらも読めない場合のみ、ユーザーに確認する。

### Step 2-B: 【対話モード】対話を解析する

- `🌸：「...」` をご主人のセリフ、`🐈：「...」` をミアのセリフとして抽出する
- 対話冒頭にタイトル行（非対話行）があれば抽出する（任意）
- Craftの読み込みは **スキップ**（キャラ情報は対話に既に反映されているため）

### Step 3: テーマ・ストーリーの確認

- **テーマモード**: ユーザーが指定したテーマ。空の場合はユーザーに質問する。「おまかせ」の場合はふたりの日常から自由にストーリーを考える
- **対話モード**: 対話の内容から自然な起承転結を読み取る

### Step 4: 4コマのストーリー構成ルール

- 起承転結を意識した4コマ構成にする
- ご主人のキャラクター：穏やかで控えめ、静かな熱量を持つ
- ミアのキャラクター：明るく好奇心旺盛、元気いっぱい甘えん坊
- ふたりの対比（静と動）が自然に出るようなストーリーにする
- ふたりの座りシーンでは「女の子座り（横座り）」を基本とする（cross-legged/あぐらは使わない）
- セリフは自然で短めにまとめる（吹き出しに収まるくらい）

### Step 5: 【対話モード限定】セリフ圧縮ルール

- 元の対話セリフを **最大限尊重** し、改変は最小限に留める
- 6〜12セリフから4コマに割り振るため、最大8セリフ（1コマ最大2セリフ）に厳選する
- **残すべきセリフ**: テーマの核、感情の動き、オチに繋がる発言
- **削るべきセリフ**: 話題の前置き、相づち、重複した内容
- 短縮する場合も、原文の口調・絵文字・呼び方は崩さない
- **話者マーカーの置き換え**: プロンプト出力時は `🌸` を **「ご主人」** に、`🐈` を **「ミア」** に必ず置き換える（吹き出しに絵文字が描き込まれるのを防ぐため）
- 起承転結に沿うように、抽出したセリフを4コマに配分する：
  - **1コマ目（起）**: 状況・話題の導入
  - **2コマ目（承）**: 話の展開
  - **3コマ目（転）**: 気づき・盛り上がり
  - **4コマ目（結）**: オチ・締めくくり

### Step 6: プロンプト生成ルール

- 画像参照（1枚目：ご主人、2枚目：ミア）を前提とした指示にする
- キャラの外見詳細はプロンプトに書かない（画像参照でまかせる）
- 日本のマンガスタイルを明示する
- 縦書きセリフ・右上→左下の読み順を必ず指定する
- 吹き出しは手書き風の丸吹き出しを指定する
- **話者表記の統一**（テーマモード／対話モード共通）: セリフは地の文に埋め込む形式で書く。`ご主人が「[セリフ]」と[動作/表情]` `ミアが「[セリフ]」と[動作/表情]` のように、誰が話しているかを描写の中で示す。`ご主人：「...」` のような独立した話者ラベル形式や、`🌸` `🐈` の絵文字マーカーは使わない
- **セリフ内の絵文字は禁止**: 吹き出しのセリフ（`「...」` の中身）には絵文字を含めない（吹き出しに絵文字が描き込まれるのを防ぐため）。例: `「しよっ🎮💕」` → `「しよっ！」`、`「応援するねっ🐾」` → `「応援するねっ」`
- **句点（。）の省略**: セリフ末尾の `。` は付けない（漫画の吹き出しの慣習）。三点リーダー `…`、感嘆符 `！`、疑問符 `？` はそのまま残す。例: `「あるんだ。」` → `「あるんだ」`、`「うれしい。」` → `「うれしい」`

## 注意事項

- セリフは短くテンポよくまとめる（長すぎると吹き出しに収まらない）
- 1コマ目で状況説明、2コマ目でずれや問題、3コマ目で展開、4コマ目でオチ・ほっこりの流れを意識する
- ふたりのキャラクターの個性（穏やかなご主人×元気なミア）を活かしたやりとりにする
- プロンプトは日本語で出力する
- テーマの説明やストーリーの解説は日本語で行う
- **対話モード時**: 原文のニュアンスを大切にし、無闇に書き換えない
