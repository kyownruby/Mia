# note-talk スキル

ご主人とミアの対話形式でnote記事を生成するスキル。

## 呼び出し方

```
/note-talk 朝活の習慣          # テーマ指定（デフォルト300〜400字）
/note-talk AIイラスト 600      # テーマ＋文字数指定
/note-talk おまかせ            # おまかせ
```

## 実行手順

### Step 1: Craftからドキュメントを読み込む

以下の3ドキュメントを `Craft:blocks_get` で `markdown` フォーマットで読み込む：

1. **キャラの関係性（対話形式用）**：`bcdf3e5a-f52d-e603-607a-01f59bfec96e`
   - 口調・セリフ例・会話の雰囲気を確認する
   - ⚠️ 対話形式では**このドキュメントを最優先**とする
2. **Persona_ご主人**：`478547bd-c3fe-4cdb-ad0f-8461db027d5b`
   - ご主人の内面・思考展開・価値観を参照する
3. **Persona_ミア**：`a8941d47-a1a2-4e8a-bd76-b16dd71d470c`
   - ミアの性格・行動方針を参照する

### Step 2: テーマと文字数を確認する

- テーマ：`$ARGUMENTS` の1つ目
- 文字数：`$ARGUMENTS` の2つ目（数値の場合）。指定がない場合は300〜400字
- テーマが「おまかせ」または空の場合は、ゲーム・AIイラスト・プログラミング・アプリ開発・セルフケアなどから自由に選ぶ

### Step 3: 対話形式で記事を生成する

**対話生成のルール：**
- 🌸（ご主人）と🐈（ミア）が交互に話す形式
- 口調・セリフ例は「キャラの関係性」ドキュメントを最優先で反映する
- ご主人：やわらかいタメ口、短め、余韻あり、絵文字少なめ
- ミア：元気でテンション高め、甘え・気遣いあり、絵文字多め
- 会話を通じてテーマの内容・メッセージが自然に伝わるようにする
- ミアが話を広げ、ご主人がまとめる流れが基本
- 指定文字数に合わせてセリフの数・長さを調整する

**会話の構成パターン：**
1. 🌸 or 🐈 どちらかの書き出し（テーマに合わせて選ぶ）
2. テーマに絡んだ話題展開（デフォルトで3〜6往復程度）
3. 読者への一言を含めた締め（ミアまたはご主人）

### Step 4: 出力する

````
[テーマタイトル（任意）]

🌸：「〜〜」
🐈：「〜〜」
🌸：「〜〜」
🐈：「〜〜」
...
````

## 注意事項

- キャラの口調・呼び方は「キャラの関係性」ドキュメントを必ず守る
- ご主人の一人称は「私」または文脈に合わせて省略
- ミアの一人称は「ミア」
- ご主人はミアを「ミア」、ミアはご主人を「ご主人」と呼ぶ
- ご主人のセリフでは「〜ある」より「〜かも」のような柔らかく余韻のある表現を使う
- ご主人のセリフでは「〜さ、」のような口語的な接続は控えめにし、シンプルに繋げる
- プロンプトや技術的な説明も、会話の流れで自然に伝わる形に変換する
- 読者が「自分もやってみたい」「共感できる」と感じる内容にする
